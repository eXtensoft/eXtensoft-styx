What it is

Turn any image into clean, machine-readable data.

Ollama Vision uses local AI vision models to read what's in your photos — text, objects, scenes, fields, structure — and hand back the result as structured JSON. Not a wall of text. Not a generic caption. Real, queryable data, shaped exactly the way you asked for it.

You decide what gets extracted by writing a small instruction template — a markdown file with a schema. The AI follows the template. The output drops into a searchable library you can filter, export, and feed into anything else. Every photo, every result, every template stays on your hardware.

The engine room

From pixels to structured data.

Most apps treat a photo as a JPEG. Ollama Vision treats it as a dataset waiting to be extracted. The leap happens via a small template you write — a markdown file with a JSON schema — that tells the AI exactly what to pull out and what shape it should come back in.

Walked through: a recipe card.

You snap or scan a recipe — handwritten card, magazine page, cookbook spread, doesn't matter. Ollama Vision applies your recipe template, the AI looks at the image, and clean, structured fields drop out the other side.

Instruction template recipe.md 
---
name: Recipe extractor
description: Pull title, yield, ingredients, and steps from a recipe image.
model: llava
jsonSchema:
  type: object
  properties:
    title:        { type: string }
    yield:        { type: string }
    prepTime:     { type: string }
    cookTime:     { type: string }
    ingredients:  { type: array, items: { type: string } }
    steps:        { type: array, items: { type: string } }
    tags:         { type: array, items: { type: string } }
  required: [title, ingredients, steps]
---
You are looking at a recipe. Extract the title, the yield,
the prep and cook times if visible, every ingredient with
its full quantity, and every step in cooking order. Tag
the recipe by cuisine and dish type.

How it works

Local AI, in plain English.

Ollama is a small program that runs AI models directly on your computer — the same kinds of models behind tools like ChatGPT, but the actual brain of it lives on your hardware. Ollama Vision is the friendly companion that talks to it. Instead of sending your pictures to a cloud, it asks the AI running right here to take a look.

01

Pick your images

Browse to a folder. Tick the photos you want analyzed, or grab the whole directory.

02

Choose what to ask

Pick an instruction set — describe-the-scene, transcribe-text, find-objects, extract-recipe — or write your own.

03

Pick a model

Different models are good at different things. Pick one. The app handles loading and warming it up.

04

Run it

The AI looks at each image and reports back. Live progress shows what's happening, image by image.

05

Browse results

Everything lands in your library. Search, filter, export. Click any image to see what the AI saw alongside the original.

The big idea: the AI never leaves your computer. There's no cloud. There's no subscription. There's no data being collected, anywhere, by anyone. Your photos stay yours.
Architecture

Modern web, classic engineering.

A single-page web application running in your browser, talking to an Ollama service running in the background on your computer. No accounts, no servers, no telemetry. Just two pieces of software cooperating quietly on your hardware.
